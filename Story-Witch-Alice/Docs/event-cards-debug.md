# Phase 3 卡牌调试版

运行 `Assets/Scenes/SampleScene.unity`，左上角自动出现时间与卡牌操作栏，无需手工挂载组件。

1. 点击「编辑牌组」。三种牌各持有 99 张；默认流星 8、维多利亚七号机 4、宇宙冷漠 8。
2. 用减号移出卡牌，再用加号加入。总数必须等于 20 才能确认。调试版本暂不限制类型比例。
3. 确认时洗牌，从 20 个槽位中不放回取 12 张，作为本轮固定序列。同一种卡可以有多个副本。
4. 点击「调试：推进一格」，展示下一张卡背并翻牌。动画结束后才能选择，结算期间不能重复推进。
5. 流星点击领取后增加 200 思绪；宇宙冷漠点击继续；维多利亚可立即进入商店或稍后访问。
6. 遗民入口保留到下一次推进时间。商店往返不推进时间，也不重新生成牌序。
7. 第 12 张结算完毕后自动进入下一轮牌组编辑。若这张牌选择进入商店，编辑界面会在返回后显示。

资源配置：`Assets/Resources/EventCardCatalog.asset` 引用了现有卡背、中文字体和维多利亚数据。
卡面目前是文字基础样式；时间只由调试按钮驱动。运行状态在本次游戏内保留，退出运行后重置，尚未接入存档。

代码入口：`EventCardSystem.AdvanceTime()`，后续可由故事完成信号调用。
`EventDeckState` 负责纯牌序和时间状态，`EventCardView` 负责界面，`EventCardSystem` 负责结算及商店衔接。

验证：Unity 菜单 `Tools > Event Cards > Validate Deck Logic` 检查 300 个随机种子的抽取与边界条件。
完整自动验证使用 Unity 批处理参数 `-batchmode -nographics -executeMethod EventCardValidation.Run -logFile <日志路径>`。
该验证自动进入运行模式，测试流星和平静各一整轮、遗民商店往返，完成后退出编辑器；只用于独立批处理进程。

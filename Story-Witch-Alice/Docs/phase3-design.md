# Phase 3 开发目标

---

## 一、优先级总览

1. **合成树系统**：静态合成树替换为动态可视化合成树
2. **商店框架**：搭建遗民商店基础框架
3. **经济系统**：以“思绪”为核心的初步经济循环
4. **时间与事件卡牌系统**：以炼制故事为时间推进单位的事件驱动系统

---

## 二、合成树系统

### 2.1 核心目标

将 Phase 2 的静态合成树 UI 替换为动态可视化合成树，增强玩家对合成进度和元素关联的直观感知。

### 2.2 功能需求

- 以树状结构展示已解锁的合成配方
- 未解锁节点以剪影或虚线轮廓显示，提示玩家存在可探索配方
- 已解锁节点显示元素图标与名称
- 支持缩放与拖拽导航
- 新元素合成完成时，树状图自动展开对应节点，带有短暂动态效果

### 2.3 动态效果

- **节点解锁动画**：新节点从父节点生长而出，伴随墨迹晕染或枝桠舒展的视觉表现
- **连线绘制动画**：节点间连线由虚线转为实线，颜色从灰暗渐变为金色
- **根节点脉动**：基础元素节点带有微弱的呼吸光效
- **合成成功反馈**：合成瞬间，树状图对应位置短暂高亮，波纹扩散

## 三、商店框架

### 3.1 核心目标

搭建遗民商店的基础 UI 与交互框架，为后续每位遗民的专属商店内容提供统一载体。

### 3.2 商店界面

- 遗民肖像与名称展示
- 遗物列表，包含物品图标、名称、价格（思绪）
- 遗物包
- 物品分类标签（物质类 / 抽象概念类）
- 购买确认弹窗
- 玩家当前思绪余额显示

### 3.3 交互流程

1. 玩家在遗民到访时时打开商店
2. 浏览遗物列表，查看物品描述与价格
3. 确认购买后扣除对应思绪，物品解锁加入合成树

### 3.4 扩展预留

- 商店框架需支持后续添加更多遗民及其专属商品
- 预留限时折扣、好感度解锁等进阶功能接口
- 预留遗民特殊对话触发条件接口（购买特定物品后触发）

## 四、经济系统

### 4.1 核心目标

建立以“思绪”为唯一货币的初步经济循环，让炼制故事与遗民评分产生实际资源价值。

### 4.2 货币定义

- **名称**：思绪
- **定位**：从故事结局中提炼出的精神价值，遗民认可的交易媒介
- **获取途径**：
  - 将炼制出的故事结局展示给遗民，遗民根据评分倾向给出相应数量的思绪
  - 触发遗民隐藏偏好时可获得额外思绪奖励
  - 特定事件或成就奖励

### 4.3 支出途径

- 向遗民购买遗物（物质类与抽象概念类）
- 后续系统扩展预留（温室花盆、特殊合成催化剂等）

### 4.4 数值基准（初步）

- 遗民评分范围：1 - 100 分
- 基础思绪获取：评分 × 基准系数
- 隐藏偏好触发：额外加成百分比

### 4.5 界面需求

- 思绪余额实时显示
- 获取思绪时弹出数值变化提示
- 支出时显示扣除动画

### 4.6 备注

- 本阶段暂不设置赚取思绪流程，因此先设置为99999方便测试

## 五、时间与事件卡牌系统

### 5.1 核心目标

以“炼制故事”作为时间推进的基本单位，建立事件驱动的世界节奏，让玩家的每次合成行为产生后续连锁反应。

### 5.2 时间刻定义

- **基本单位**：1 次炼制 = 1 个时间刻
- 每次将元素与爱丽丝投入坩埚生成故事结局，计为一个时间刻
- 时间刻仅由炼制行为推进，不依赖现实时间

### 5.3 牌堆机制

- **牌堆总量**：20 张事件卡牌
- **抽取机制**：每 12 个时间刻为一个事件轮次，从 20 张牌堆中随机抽取 12 张作为下一轮次的事件序列
- **调整窗口**：每 12 个时间刻结束后，玩家可调整牌堆组成（增删卡牌、修改比例）

### 5.4 事件类型（初步）

- **问号牌（随机事件）**：触发不可预测的世界事件，可能获得思绪奖励，解锁新配方等
- **遗民牌（遗民到访）**：特定遗民在事件触发后进入可交互状态，玩家可向其展示故事或购买遗物
- **故世牌（往日投影）**：揭露灾难之前发生的事情，展示世界观和遗民背景故事
- **神谕牌（buff）**：提供临时或者永久的增益，比如思绪获取倍率
- **预留类型**：后续可能添加世界切片牌、灾变牌、特殊爱丽丝牌等

### 5.5 事件触发流程

1. 玩家完成炼制，推进 1 个时间刻
2. 若达到事件触发节点，从当前牌堆中抽取事件
3. 事件以卡牌翻转动画呈现
4. 玩家处理事件（选择、确认、交互）
5. 事件处理完毕后继续正常游戏流程

### 5.6 牌堆编辑

- 玩家可在调整窗口打开牌堆编辑器
- 查看当前 20 张牌堆组成
- 从已解锁的事件卡牌中选择替换
- 牌堆中同类型卡牌数量受上限限制
- 调整完成后锁定牌堆，进入下一轮 12 时间刻周期

### 5.7 界面需求

- 时间刻计数器显示（可能与主场景钟表联动）
- 当前牌堆剩余事件预览（可选）
- 事件触发时的卡牌动画
- 牌堆编辑器界面

### 5.8 备注

- 由于炼制故事功能暂时未完备，因此先由触发器占位以推进时间
- 每种卡牌有其最大上限，避免向某一方倾斜过多，具体数值待定

## 六、系统关联

### 6.1 炼制 → 经济 → 商店 循环

```
炼制故事（推进时间刻）
→ 获得故事结局
→ 向遗民展示故事换取思绪
→ 用思绪购买遗物
→ 新遗物解锁新合成配方
→ 炼制新故事
→ 循环
```

### 6.2 时间刻 → 事件 → 遗民到访

```
推进时间刻
→ 触发事件卡牌
→ 遗民牌：遗民到访，可展示故事或交易
→ 问号牌：触发随机事件，可能影响经济或合成
→ 继续推进
```

# 故事魔女爱丽丝 (Story Witch Alice)

> 在概念消散的尽头，用坩埚追忆万物，让AI为每一次追忆书写独属于爱丽丝的结局。

---

## 🧪 游戏简介

世界正在遗忘。

一个又一个概念从世上消散——火不再是火，羊不再是羊。万物坍缩为虚无，只剩残存的"概念碎片"散落在世界泡的孤岛上。

你面前有一口坩埚、一本近乎空白的合成笔记、以及一个只记得自己名字的少女——**爱丽丝**。

从"火、水、石、气、时间"这些概念燃烧后的灰烬出发，两两或三三组合，追忆那些已被世界遗忘的事物。将追忆之物与爱丽丝一同投入坩埚，便能窥见一条世界线上的**故事结局**——概念可以被合成，但只有通过爱丽丝，它们才能被编织成有意义的故事。

---

## 🎯 核心特色

- **手写合成表 + AI叙事**：合成逻辑由策划控制，保证追忆之路的趣味与平衡；故事的编织交给AI，为每一次炼制带来独一无二的叙事可能。
- **书宠交互系统**：合成笔记"熵"以魔法书宠的形态陪伴玩家。鼠标悬停时书页轻翻，点击展开完整的物品栏与合成树——那些被重新追忆的概念，将在此重聚。
- **面向对象的元素设计**：每个概念以结构化数据存储（词元、属性、标签等），通过CSV批量导入，方便维护与未来接入AI。
- **物理拖拽合成**：概念碎片以2D物理物体形式拖拽入坩埚，支持碰撞、抛物线惯性、重复拾取，追忆的手感应当真实。
- **千面爱丽丝**：特定结局将揭示其他世界线下"爱丽丝"这个概念的可能性。解锁不同身份的爱丽丝——她们人格各异，面对同样的概念碎片，会编织出风格迥异的故事。
- **遗民与思绪**：世界遗忘的幸存者——遗民，掌握着无法通过普通合成获得的"遗物"。用故事结局换取他们的"思绪"货币，解锁更深层的追忆配方。
- **饰品系统（预留）**：特定结局解锁饰品，穿戴在爱丽丝立绘上，作为故事之旅的纪念。

## 🌍 世界观速览

| 关键词 | 说明 |
|--------|------|
| **大遗忘** | 某一天，世界开始遗忘。概念逐一消散，万物坍缩为虚无。这是末日后残存的孤岛。 |
| **概念碎片** | 曾经完整概念燃烧后的灰烬。火、水、石、气、时间——它们是万物消解后仅剩的遗骸。 |
| **坩埚** | 古老的炼金工具。将概念碎片投入坩埚，便能追忆出已消散的事物。这是对抗虚无的唯一手段。 |
| **合成笔记「熵」** | 伴随坩埚的记录工具。追忆出的概念会自动绘入树状图。它几乎空白——世界遗忘了太多，连笔记自己也不记得曾经记录过什么。 |
| **爱丽丝** | 被遗忘本身所遗忘的少女。她是一面镜子，反射概念的意义。将她与元素一同投入坩埚，不会合成新概念，而是生成一段故事结局。 |
| **遗民** | 在大遗忘中幸存的意识体。掌握着需要记忆锚点才能获取的遗物。用故事打动他们，换取遗物与真相的碎片。 |
| **虚无** | 概念消散后的最终产物——彻底的"无意义"。它是威胁，也是催化剂；投入坩埚可剥离元素的表层意义，揭示更本质的概念结构。 |
